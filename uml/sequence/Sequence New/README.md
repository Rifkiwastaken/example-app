## Cara Menggunakan

1. Buka file **00_use_case_overview.puml** untuk melihat use case secara visual.
2. Untuk setiap use case di atas, buka file sequence yang sesuai (mis. UC01 → `01_kelola_data_tanaman.puml`).
3. Render file `.puml` dengan PlantUML (VS Code extension, plantuml.com, atau CLI).
